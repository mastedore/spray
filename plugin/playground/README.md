# Spray Playground
This folder contains the source code for the [Spray playground game](https://www.roblox.com/es/games/130730172678468),
A system where users can easily and lively test the Spray library.

The playground code was generated completely by Claude Opus 5.5.

The same folder is also the playground inside the [Spray plugin](../README.md), so one edit here
reaches both. `Game.client.luau` is the game's entry point and the only file the plugin leaves out;
`App.luau` starts everything else, and `Host.luau` / `Input.luau` are where the two differ.
